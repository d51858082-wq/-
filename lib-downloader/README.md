# ✿ Lib Downloader

Десктопное приложение для Windows (Python + Tkinter) с входом в аккаунт, поиском и очередью загрузки:

- **Манга** с Mangalib / Hentailib → **PDF** (глава = PDF или том = PDF)
- **Аниме** с AnimeLib → **mp4** (выбор качества, докачка)
- несколько тайтлов одновременно, несколько потоков внутри тайтла
- тёмная тема, оригинальные чиби-девочки и свой арт-фон (любая твоя картинка)

> Проект использует неофициальный API сайтов — он может меняться. Скачивай только для личного
> офлайн-использования и соблюдай правила сайтов и законы об авторском праве.

## Без Python: получить готовый exe (через GitHub, ~5 минут, ничего устанавливать не нужно)
1. Зарегистрируйся на github.com (бесплатно) и нажми **New repository** → назови `lib-downloader` → **Create**.
2. На странице репозитория нажми **uploading an existing file**, перетащи туда **всё содержимое
   распакованной папки** (включая папку `.github`) и нажми **Commit changes**.
3. Открой вкладку **Actions** → слева **Build Windows exe and installer** → **Run workflow**.
4. Через 5–10 минут открой завершённый запуск и скачай внизу архив **LibDownloader-windows**.
   Внутри `LibDownloader-Setup.exe` (установщик) и `LibDownloader.exe` (без установки).
   Python на твоём компьютере не нужен.

## Вход через VK / Google и др.
Кнопка **«Войти через сайт»** открывает настоящий сайт Mangalib в окне программы: нажми там «Войти»
и входи любым способом, как обычно. Как только вход завершится, окно закроется, а программа получит
токен. Для окна нужен Microsoft Edge WebView2 (есть в Windows 11 и в большинстве Windows 10;
если нет — поставь [отсюда](https://developer.microsoft.com/microsoft-edge/webview2/)).
Если какой-то способ входа сайт блокирует во встроенном окне (иногда так делает Google), войди
через VK/почту или используй «Войти по токену…».

## Установка

### Вариант 1. Установщик в один клик (рекомендуется)
Скачай `LibDownloader-Setup.exe` из раздела **Releases**, запусти и нажми «Далее» → «Установить».
Python и другие программы ставить **не нужно**: всё уже внутри. Установщик не требует прав
администратора, создаёт ярлыки (меню «Пуск» и по желанию рабочий стол) и удаляется как обычная
программа через «Параметры → Приложения».

Если Windows показывает «Защитник Windows предотвратил запуск…», нажми **Подробнее → Выполнить в любом
случае**: файл не подписан платным сертификатом, поэтому SmartScreen и некоторые антивирусы
перестраховываются. Исходники открыты, можно собрать самому.

Без установки: можно скачать просто `LibDownloader.exe` и запускать его.

### Вариант 2. Из исходников
1. Скачай репозиторий (**Code → Download ZIP**) и распакуй.
2. Запусти `install.bat`, затем `run.bat`. Если Python не установлен, `install.bat` сам скачает и поставит его (без прав администратора).

Или вручную:
```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python lib_app.py
```

### Сборка exe самостоятельно
Запусти `build_exe.bat` — получишь `dist\LibDownloader.exe`.
Автосборка на GitHub: создай тег (`git tag v1.0.0 && git push --tags`) — Actions соберёт exe и
приложит к релизу `LibDownloader-Setup.exe` и `LibDownloader.exe`.

## Использование
1. **Вход:** логин и пароль, либо «Войти по токену…», либо гость (без 18+).
   Сохраняется только токен (`~/.lib_downloader.json`), пароль не хранится.
2. Выбери раздел, найди тайтл, добавь в очередь (двойной клик или «В очередь»).
   Можно добавить и по ссылке.
3. Настрой режим PDF, качество аниме, потоки, папку → **Скачать очередь**.

### Как получить токен
Открой сайт, залогинься → `F12` → **Application** → **Local Storage** → скопируй значение ключа
`auth` целиком и вставь в «Войти по токену…».

## Если что-то не работает
- Картинки манги не грузятся → в `lib_downloader.py` поменяй `IMG_BASE`
  (например, на `https://img3.mixlib.me`).
- Аниме: качаются только серии с собственным плеером Animelib; внешние плееры пропускаются.
- Вход по паролю может блокироваться капчей/2FA — используй вход по токену.
- Открой Issue и приложи строки из лога.

## Структура
```
lib_app.py          вход, поиск, очередь (запускать этот файл)
lib_downloader.py   логика загрузки и оформление
install.bat / run.bat / build_exe.bat
installer.iss       скрипт установщика (Inno Setup)
.github/workflows/build.yml   автосборка exe
```
